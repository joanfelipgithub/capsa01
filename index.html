File Converters — DXF ⇄ SVG

DXF → SVG

LINE, CIRCLE, ARC, LWPOLYLINE / POLYLINE (with bulges), TEXT. Layers become SVG groups with their AutoCAD colour. Mirrored (extrusion −Z) entities are corrected.

SVG → DXF

Paths (lines, curves, arcs), rect, circle, ellipse, polyline/polygon, text, nested transforms, Inkscape layers. Physical size is taken from width + viewBox.
